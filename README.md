# forge2iq

forge2iq is a web-based production management platform for manufacturing and printing operations. It gives each team on the factory floor its own workspace and keeps the whole operation, from customer order to dispatch, in one place.

## What it does

- **Production tracking**: work orders, shift reports, shift entries, downtime logging and production reports
- **Printing management**: printing shift logs, stock items and sheet receipts
- **Dispatch**: logging outgoing dispatches and confirming receipt
- **Handover notes and messaging**: so information carries over between shifts and teams
- **Dashboards and stats**: daily, weekly and monthly figures, with PDF and Excel exports
- **Multi-company and role-based access**: company admin, production manager, printing manager, dispatcher and office manager roles, with an audit log of changes

## Tech stack

- **Backend**: Java 17, Spring Boot, Spring Security (JWT), PostgreSQL
- **Frontend**: React, TypeScript, Vite, Material UI, installable as a PWA
